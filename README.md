# MOVElic: Public Transport in Indonesia - History, Insights & 3D Models

## About
This is a static web application built using native technologies (HTML, CSS, and JavaScript) that provides an in-depth look into the history and insights of public transport in Indonesia. It also features 3D models of various public transportation vehicles used across the country, offering an interactive experience for users to explore how public transport has evolved in Indonesia.
## Features
- **Historical Timeline**: A visual timeline showcasing the evolution of public transport in Indonesia.
- **Transportation Insights**: Articles and statistics about different modes of public transport (trains, buses, ferries, etc.) in Indonesia.
- **Public Transport Gallery**: A collection of images showing past and present public transportation vehicles.
- **Sustainability**: Insights into how public transport is contributing to sustainable urban development in Indonesia.
- **3D Models**: Interactive 3D models of various public transport vehicles (buses, trains, etc.) used in Indonesia.

## Tech Stack
- **Frontend**: HTML, CSS, and JavaScript
- **Icons**: Font Awesome for using vector icons
- **Images**: Responsive images to showcase transport vehicles and infrastructure
- **3D Models**: Three.js for rendering interactive 3D models of public transport vehicles
